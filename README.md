# QA Engineering Assessment Portfolio

This repository contains a comprehensive, end-to-end Quality Assurance testing suite solved for a dual-part ecosystem assessment. It demonstrates proficiency in Manual Testing engineering, API endpoint verification, Database validation, and UI Automation.

---

## 📌 Project Overview

### 1. E-Commerce Web Application (End-to-End Manual Testing)
A full-scale functional and non-functional test coverage suite designed for an online shopping application.
* **Modules Covered:** User Management, Product Catalog, Shopping Cart, and Checkout/Payment Gateway.
* **Deliverables Included:** Core Test Plan, Requirement Traceability Matrix (RTM), 60+ executed Test Cases, systematic Bug Tracking Sheet, and a Test Summary Report.

### 2. Student Management System (Backend & UI Automation Testing)
Robust validation frameworks engineered to verify backend architecture stability and database layer consistency.
* **API Testing:** Postman automated test collection validating HTTP status codes, JSON payload schemas, authorization layers, and edge-case boundary mutations.
* **Database Verification:** Rigorous SQL scripts designed to enforce CRUD logic, strict data integrity constraints, foreign key mappings, and interface data synchronization.
* **UI Automation:** Robust, maintainable UI automation test scripts handling critical flows including user onboarding, secure sessions, dynamic queries, and state updates.

   ```bash

   ```
3. Install dependencies:
   ```bash
   # For Node.js (Cypress/Playwright):
   npm install
   ```
